ACT I OF III · CALENDAR & HANDOFF

Why We Built It

ChatGPT is single-player. A household isn't.

Running a home takes two people coordinating across calendars, grocery lists, deliveries, and budgets. Standard AI chat traps every conversation inside one person's private browser tab.

Shared rooms plus locked 1-on-1 desks

Both partners talk with the agency together in #kitchen, #shopping, and #interiors. For personal tasks, each partner has a locked private channel (#partner-a-desk and #partner-b-desk) where personal Gmail, work calendars, and medical superbills stay private to that person.

Built on Discord instead of another mobile app

The iOS app already handles push notifications, voice notes, photo uploads, and approval buttons. When you ask a multi-step question in a main room, a fast classifier opens a dedicated thread automatically so the main channel stays easy to scan.

Pinned messages instead of a separate web dashboard

Nobody wants another web portal to check. Instead, the specialists keep pinned messages in Discord updated in place: this week's dinner menu in #kitchen, expiring credit card credits in #shopping, and monthly cloud spend in #ops.

Memory & Continuous Delivery

A house that remembers and updates itself.

01 · Self-Writing Git Handbook

60-second hot reload

Agent instructions, schedules, tool permissions, and the shared House Binder live in Git and reload every 60 seconds. When an agent records a new family preference or you tap "Always allow" on a tool in Discord, the server commits and pushes that change back to Git.

02 · Three Local SQLite Databases

Structured state on disk

Household records live in three SQLite files on the home server: Kitchen DB (meal plans, pantry, grocery list, lunchbox history), Perks DB (card credits, reset dates, subscription checks), and Usage DB (token counts and monthly dollar spend).

03 · Throwaway Briefings & Auto-Rollback

Clean chat, safe deploys

Morning briefings and inbox watches run in fresh throwaway sessions so status posts never clutter your chat logs. Every 5 minutes, the server checks Git, waits until no conversation is active, runs 8 live health checks, and rolls back automatically if a check fails.

Hard Boundaries

Four rules that can't be prompt-injected away.

Approval Gate · $0 Direct Spend · Vault Redaction · Card-Only Sync

Discord approval for edits & zero direct spend

External edits, bookings, and portal submissions pause behind an explicit Approve button in Discord, and no agent can spend money directly. Agents can stage carts, links, and forms, while a human always completes checkout.

No static passwords on disk

1Password resolves API keys and logins in memory on demand. Every secret is registered with an output filter that replaces raw values with [redacted] before anything reaches Discord or a log file.

Never guess credentials

Agents are forbidden from guessing usernames, emails, passwords, or 1Password item names. Browserless blocks plain-text typing into password fields and pauses all logins for 15 minutes if any login fails.

Filtered financial sync

Monarch Money syncs credit card charges and recurring bills so Sterling can flag unused card perks, without exposing bank balances, paychecks, investments, or net worth.

Quality & Cost Control

Fast replies without runaway cloud bills.

Argon Judgment · Flash Sub-Agents · Backstage QC · 10m Cache

Argon for judgment, Flash for reading

Gemini Argon runs live chat turns. When an agent needs to read retail pages, it spawns up to four read-only Gemini Flash sub-agents in throwaway sessions so raw HTML stays out of the main conversation.

Two-step reply check

Before any reply posts to Discord, a fast rule check blocks invented links, fake Amazon IDs, and uncalled tools. Then a Gemini Flash reviewer checks the draft against that specialist's handbook and tool outputs.

Routine graduation

Scheduled routines load only the three to five tools they actually need. New routines start on Argon while Flash quietly replays the same tool outputs; three matching runs unlock a one-tap switch to Flash in #ops.

10-minute Browserless page cache

Parsed product specs, studio photos, and recipes stay cached on disk for 10 minutes so follow-up questions about dimensions or ingredients answer in milliseconds.

Local MCPJungle Gateway

Nine integrations wired into the house.

Every home appliance, grocery store, calendar, and financial feed connects through a single on-premises MCPJungle gateway that enforces per-specialist tool allowlists and scrubs secrets from outputs.
