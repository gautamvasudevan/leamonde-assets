Private Household AI Agency · Self-Hosted on Proxmox VE

An intelligent home staff that lives in multi-player chat, remembers how the house runs, and keeps every secret at home.

Standard AI apps are single-player: two partners can't sit in one chat room to plan dinner, compare rugs, or coordinate calendars together while keeping their personal emails separate. Leamonde AI runs six independent specialists on a home server and puts them inside a private family Discord.

01 · Multi-User Front End

Discord gives both partners shared specialist rooms plus locked 1-on-1 desks—with voice notes, photos, threads, and approval buttons on every phone.

02 · Home Server + Cloud Brain

A Proxmox VE home server runs the Antigravity SDK harness, local databases, and tool containers; Google Gemini handles reasoning and voice.

03 · Six Separate Minds

Each specialist is an isolated agent with its own prompt, memory, and tool allowlist—backed by MCPJungle for tools and 1Password for secrets.

04 · Memory & The Vault
How the House Remembers

Three Purpose-Built Storage Tiers

1. Git Handbook & House Binder (YAML + Markdown) 60s Hot-Reload

Holds agent instructions, channel layout, tool rules, and the House Binder (shared facts in knowledge/*.md + private notes). Bidirectional: when staff learn a lasting fact or you tap "Always allow", they commit and push directly back to Git.

2. Three Local SQLite Databases Live Pinned Boards

Kitchen DB (meals, pantry, groceries, recipes, kid's lunchbox rotation), Card Perks DB (cards, credit resets, subscription audits), and Usage DB (token & dollar spend)—powering self-updating pinned boards in Discord.

3. On-Disk Conversation & Throwaway Sessions Crash-Resilient

Chat histories persist on disk per (agent, channel/thread). Daily briefings and email watches run in fresh throwaway sessions so they never bloat chat history, leaving a short carry-over note for follow-up questions.

How the House Stays Safe

Four Hard Privacy & Credential Locks

🔐 1Password On-Demand + Live Output Redactor 0 Passwords on Disk

Only a read-only vault token sits on disk. All keys and logins resolve from 1Password on demand and register in an in-memory Redactor that scrubs secret strings ([redacted]) from every tool output, log, and reply.

🚫 3-Layer "Never Guess Credentials" Rule 15m Lockout

Agents never invent or vary logins or vault item names. Enforced in prompts and hard-coded in the browser—which blocks plain-text password fills, checks an op:// allowlist, and locks all logins for 15 minutes on any failure.

🚪 Physical Private Desks & Human Checkout Scope Gated

Personal Google tools and claims skills don't exist outside that partner's private desk. Instacart order placement is stripped from code (humans always check out in the app), and Monarch Money excludes bank balances, paychecks, and net worth.

05 · Speed, Cost & Connected Tools
Model & Operations Strategy

High Reasoning Quality Without Runaway Cloud Bills

Argon for chat · Flash for sub-agents, QC & graduated routines
1. Parallel Flash Sub-Agents

Up to 4 read-only Flash sub-agents read noisy web pages in throwaway sessions and return clean briefs—keeping the parent Argon chat history small.

2. Two-Stage Backstage QC

<1ms rule checks catch broken tables, fake tool claims, and unverified links, followed by a Flash critic checking house rules before any reply posts.

3. Evidence-Based Graduation

Routines load only 3–5 tools and start on Argon while Flash shadow-replays the same tool outputs. 3 matches unlock a 1-click switch to Flash in #ops.

4. Self-Healing Pull Deploys

Home server polls Git every 5m, waits for idle, runs 8 live pre-flight checks (staff selftest), swaps in, and auto-rolls back if health fails.
